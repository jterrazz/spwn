# Preferences

Machines keeps its own choices in one file, `~/.config/station/preferences.json`, and reads a few environment variables once at start. Neither is a setting: [Settings](settings.md) is what Machines sets up on a machine ([ADR-015](../decisions/015-preferences-json.md)).

| Section          | Answers                                           |
| ---------------- | ------------------------------------------------- |
| preferences.json | The file, its groups, the family that writes each |
| Environment      | The variables Machines reads, all resolved once   |

## preferences.json

```json
{
    "name": "macbook",
    "macs": {
        "mac-mini": { "user": "agent", "key": "~/.ssh/id_ed25519", "lan": "192.168.1.20" }
    },
    "vm_user": "you",
    "user_email": "you@example.com",
    "user_name": "Jane Doe",
    "ports": { "max_per_vm": 10 },

    "off_here": ["dock-spacer"],
    "never_sleeps": true,
    "machinefile": {
        "name": "macbook-pro",
        "bound_at": "2026-11-10T09:12:00Z",
        "source": {
            "name": "studio",
            "url": "https://github.com/jterrazz/spwn.git"
        }
    }
}
```

The file is a set of groups. Each is owned by one family and written only by that family's calls (the rule `one-writer-per-store`); the order is the one `wire` lists them in, and a group left empty is not written. No secret is in it.

| Group                     | Family        | Holds                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | Written by                                                  |
| ------------------------- | ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------- |
| `name`                    | `setup`       | this machine's name                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | `station init`                                              |
| `macs`                    | `machines`    | the other Macs this one drives: `user`, `key`, `lan` (the address it last answered with on your LAN, which `machines unlock` dials), and when it last answered with the VMs it held then, what it is (its hardware address among it, which `machines wake` sends to), and `tell_back` while a wake or a remind waits to tell of its answer. A name or a `user` that is not one word of letters, digits, `.`, `_` and `-`, or that starts with `-`, is refused by `machines add` and, written by hand, by every command that names that Mac: every list leaves it out, never asked, and says why under Needs you. So is a `key` holding a space, a quote, `#`, `%`, `\` or a control character, which ssh_config would read apart, and this Mac's own such `key` writes no block at all; so is a `lan` that is no IP address nor DNS name, which is never stored from another Mac's answer                                                                    | `machines add`, `machines forget`, every list               |
| `vm_user`                 | `machines`    | the one login of every VM; unset, this Mac's account is taken. Either is read by one rule (`machines/contract.CheckVMUser`): a lowercase short name, a-z first, then up to 31 of a-z, 0-9, `_`, `.` and `-`, never a dot last, never `admin` nor `root`, so `jterrazz.ops` passes; a guest refuses an account of its own (`daemon`, `nobody`) by its uid. A name it refuses stops a create, an image build, and the start or restart of a macOS workspace, before any VM is made or run, and `machines ssh` to a VM of this Mac, its hint `set vm_user in ~/.config/station/preferences.json`; the `~/.ssh/config` blocks keep what they held, the list saying why they were not refreshed, and the engine dials no VM as it: a VM left running says so in the list and on its page, with that hint. No other command reads it. `station init` writes this Mac's account only when the rule takes it, else it leaves `vm_user` unset and says so in one line | `station init`                                              |
| `user_email`, `user_name` | `setup`       | the owner's git identity                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | `station init`                                              |
| `ports`                   | `ports`       | the policy of [shared ports](ports.md#the-policy): `range`, `max_per_vm`, `https`, and `not_shared`, the ports stopped sharing as `<vm>:<port>`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | by hand; `ports stop-sharing`, `ports share`, `ports https` |
| `off_here`                | `settings`    | the settings turned Off here on this machine                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `settings off`, `settings apply`                            |
| `never_sleeps`            | `awake`       | this Mac never sleeps: the engine's `awake` job holds it                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | `settings apply never-sleeps`, `settings off never-sleeps`  |
| `machinefile`             | `machinefile` | `name`, the Machinefile this machine carries, set by `station init --machinefile` and `station apply --machinefile`, and `bound_at`, when it was bound, past which the engine's first night falls; `source`, the shared source: its `name` and its git `url`, cloned at its default branch into `~/.cache/station/sources/<name>` ([Machinefiles](machinefiles.md#sources-and-origins))                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | `name` by apply, `source` by hand                           |

An unset `user_email` stays unset: the git email row accepts any value git holds, and setting up commit signing refuses to generate a key for no address. An unset `user_name` stays unset the same way: the git name row accepts any value git holds, and the same refusal names `user_name`.

A key no group names is dropped at the next write. A `v` field names the version of the shape the file was written at; absent, it is version 1, and a file a newer station wrote is refused rather than read. A file that does not parse stops every command that reads it with its line, never overwritten.

## Environment

`wire` reads the environment once and passes typed options down; no other package reads a variable.

| Variable                                                               | Read for                                                                                                                                                                                              |
| ---------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `AGENT_PASSWORD`                                                       | pre-fills the `autologin` form                                                                                                                                                                        |
| `MISE_DATA_DIR`                                                        | where mise keeps its shims                                                                                                                                                                            |
| `NO_COLOR`, `COLUMNS`                                                  | the output form and width                                                                                                                                                                             |
| `XDG_CONFIG_HOME`, `XDG_DATA_HOME`, `XDG_STATE_HOME`, `XDG_CACHE_HOME` | the folders Machines uses, when absolute ([Disk](disk.md#the-folders))                                                                                                                                |
| `STATION_TERMINAL`                                                     | this terminal's id, which `station use` keeps its machine under ([Machines](machines.md#this-terminals-machine))                                                                                      |
| `STATION_SESSION`                                                      | the session the CLI's gestures are done for, by its name: a VM's creator and a journal line's `By`, `you` without it ([Machines](machines.md#the-commands), [The journal](journal.md#what-writes-it)) |
| `GOENV`                                                                | where `station init` writes Go's env file; `off` writes none                                                                                                                                          |
| `TART_HOME`                                                            | set by the tart launcher, never by the owner ([Disk](disk.md#tart))                                                                                                                                   |
| `STATION_PUBLIC_HOST`                                                  | set inside a VM by its shell block: the public name its ports are shared at ([Ports](ports.md#what-a-package-sets))                                                                                   |
| `STATION_GITHUB_API_URL`                                               | the GitHub API origin, so a spec can point it at a stub                                                                                                                                               |
| `STATION_SYSTEM_DIRS`, `STATION_MACHINE_KIND`                          | which system folders count, and the machine kind, for a spec                                                                                                                                          |
| `STATION_SYSTEM_ROOT`                                                  | the root `/Applications`, `/opt/homebrew`, `/usr/local`, `/Library` and a VM's `/proc` are read under, for a spec                                                                                     |
| `STATION_KERNEL_STUB`                                                  | a folder of recorded kernel tables a Mac's activity is read from, for a spec                                                                                                                          |
| `STATION_POWER_STUB`                                                   | a folder whose files are the IOKit reading and whose calls go to `$HOME/.calls`, for a spec                                                                                                           |
| `STATION_GUEST_SSH_PORT`                                               | the port the engine dials a VM's sshd on (default 22), for a spec's stub sshd                                                                                                                         |
| `STATION_WORLD`, `STATION_WORLD_SEED`, `STATION_WORLD_HYPERVISOR`      | the spec build's world file, its seed and its hypervisor ([Test](../guides/test.md#a-use-case-over-a-world)); the release build reads none                                                            |
