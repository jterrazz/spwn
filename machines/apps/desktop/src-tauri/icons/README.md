# The window's icon

The spwn mark, version Papier: three dots rising on a diagonal, ink on a white ground (`spwn-light.svg`), white on a graphite ground in the dark appearance (`spwn-dark.svg`), and white on black for the system to tint (`spwn-tinted.svg`). Each is a 1024 canvas holding the macOS tile, 824 px centred with its drop shadow, as Apple's template draws it. The rasters Tauri bundles, `icon.png` (512 px) and `icon.icns`, are made from the light source alone, in the Linux VM and never on a Mac: render `spwn-light.svg` to a 1024 PNG with a transparent background in the bench's Playwright Chromium, then run `npx tauri icon <that png> -o <scratch folder>` from `apps/desktop` and copy back only `icon.png` and `icon.icns`. So the app shows the light icon in every appearance: a dark and a tinted icon on macOS need an Icon Composer `.icon` (or an asset catalog) built from the dark and tinted sources and compiled by Xcode's `actool` into the bundle's `Assets.car`, a step on a Mac with Xcode that this folder does not run yet.
